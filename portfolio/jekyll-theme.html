jekyll-theme-coderic

The single-source theme used by all seven Coderic portal sites. Dark-mode first, bilingual, OAuth2-ready. Deployed via Cloudflare Pages.

Quick start

# _config.yml
remote_theme: Coderic/jekyll-theme-coderic
plugins:
  - jekyll-remote-theme
