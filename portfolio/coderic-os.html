CodericOS

A Fedora-based Linux distribution designed for Coderic developers. Comes preconfigured with the Prodaric suite, development toolchains, and Coderic IDE. The goal is a zero-friction workstation — clone a repo and start coding.

Design philosophy

"No seguir en la edad de piedra reinventando la rueda. Pensar inteligente es avanzar el desarrollo sostenible." CodericOS does not reinvent the wheel — it stands on Fedora's shoulders and adds only what the Coderic workflow requires.

Included tools

  • Prodaric CRM / ERP
  • Coderic IDE (Theia)
  • Docker + Podman
  • Node.js / Python / Go
  • Git + SSH config
  • Coderic CLI tools
