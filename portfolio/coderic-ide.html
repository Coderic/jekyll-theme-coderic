Coderic IDE

A purpose-built integrated development environment for the Coderic ecosystem. Based on Eclipse Theia, the same foundation as VS Code and Gitpod.

Planned features

  • Native Coderic Hub API explorer
  • One-click deploy to Coderic Cloud
  • Prodaric module scaffolding wizard
  • Built-in OAuth2 credential manager
  • Pre-installed extensions for the Coderic stack

Coderic IDE is currently in the planning phase. Interested contributors are welcome to join the discussion on GitHub or through the community at coderic.dev.
