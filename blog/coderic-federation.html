La Federación Coderic: siete portales, un ecosistema

The Coderic ecosystem is made up of seven specialized portals. Each has a distinct responsibility. None duplicates the others. Here is how they fit together.

One theme, seven portals

All seven portals share jekyll-theme-coderic via remote_theme. Navigation, colors, footer, and authentication are consistent. What differs is the _config.yml values (portal_id, network) and the page content.

Portal Role Metaphor
coderic.org Incubator & corporation The kitchen
financial.coderic.com Financial services The dining room
coderic.cloud Cloud infrastructure The infrastructure
coderic.net APIs & data hub The network
coderic.dev Developer community The workshop
coderic.com Commercial gateway The storefront
coderic.store Hardware e-commerce The warehouse

The no-duplication rule

Each portal owns its content domain. If coderic.org describes the incubator model, coderic.dev does not repeat it — it links to it. If coderic.cloud lists infrastructure pricing, coderic.com does not mirror it. This discipline keeps SEO clean and content authoritative.

Integration via Coderic Hub

Runtime integration between portals happens through coderic.net: public APIs, shared datasets, MQTT endpoints. No direct cross-portal HTML dependencies. Each portal is independently deployable to Cloudflare Pages.
