Minimal layout

Clean, centered column. Maximum reading width is 48rem (max-w-3xl). Header, subnav, and footer still use max-w-7xl, so the chrome always extends edge-to-edge.

When to use this layout

Use the minimal layout for any page where the primary value is text: policy documents, blog posts, changelogs, or documentation articles. The narrow column improves readability and reduces cognitive load compared to wider containers.

How it is implemented

The default layout in _layouts/default.html provides only a bare <main> wrapper. Each page is responsible for its own container class. This page uses max-w-3xl mx-auto px-6 inside an <article> element. 

<article class="py-24">
  <div class="max-w-3xl mx-auto px-6">
    <h1>...</h1>
    <p>...</p>
  </div>
</article>
