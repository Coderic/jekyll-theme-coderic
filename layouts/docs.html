Docs layout

A two-column layout with a sticky sidebar on the left and the main article content on the right. The sidebar collapses on mobile; the content column becomes full-width.

Structure

The outer wrapper uses max-w-7xl mx-auto px-6. Inside, a flex row holds the aside and the article. The article uses flex-1 min-w-0 max-w-3xl. 

<div class="flex gap-12">
  <aside class="hidden lg:block w-56 shrink-0">
    <!-- sticky ToC -->
  </aside>
  <article class="flex-1 min-w-0 max-w-3xl">
    <!-- page content -->
  </article>
</div>

Sidebar

The sidebar uses sticky top-48 so it stays visible while scrolling. top-48 accounts for the fixed header height (pt-40 on <main>). Anchor links inside reference id attributes on headings.

Responsive behavior

The aside uses hidden lg:block. Below the lg breakpoint (1024 px) the sidebar disappears and the article becomes full-width — no extra CSS needed.
