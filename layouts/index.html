Theme demo

Layouts

Page layout patterns available in the Coderic theme. Each variant uses the same default base layout — only the content structure inside <main> differs.

Minimal

Centered prose, no sidebars. Ideal for documentation articles, blog posts, and legal pages.

Landing page

Hero + conversion blocks. Used by the portal homepages across the Coderic ecosystem.

Docs

Left sidebar table of contents + main content column. Used by coderic.net and API references.

Portal / SaaS

Vertical nav + content panel. Used by authenticated areas and Prodaric application screens.

Default home

Full-bleed hero with the enterprise component. This is the theme's root index.html.
