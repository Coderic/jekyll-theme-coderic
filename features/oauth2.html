OAuth2 / OIDC

The theme wires an Auth0-compatible SPA SDK via a JSON config block injected by Jekyll. No backend required — the entire flow runs in the browser.

Config injection

header.html renders a <script type="application/json" id="coderic-oauth2-config"> block that the SDK reads on startup. Values come from _config.yml. 

# _config.yml
oidc_client_id:  "GZ0eS1P9Y7C8p6kt8d4LIdojgHvkB5Sg"
oidc_domain:     "auth.coderic.org"
oauth_demo_sign_in: false

Authentication flow

  1. User clicks Sign In in the header.
  2. Browser redirects to the OIDC provider (auth.coderic.org).
  3. After login, provider redirects back to /callback/.
  4. The callback page exchanges the code for tokens and stores them in memory.
  5. User is redirected to /profile/ or the original destination.

Included pages

  • /callback/ — token exchange handler
  • /profile/ — Coderic ID
  • /oauth-demo/ — flow notes
  • /docs/auth0/ — integration docs
