Feature

Dark mode

The theme ships with dark mode enabled by default via a dark class on the <html> element. Light mode is a CSS override.

CSS custom properties

All colors are defined as variables in _includes/head.html:

:root {
  --bg-surface:      #ffffff;
  --bg-surface-alt:  #f8fafc;
  --text-base:       #0c0a09;  /* stone-950 */
  --text-muted:      #292524;  /* stone-800 */
}
.dark {
  --bg-surface:      #050505;
  --bg-surface-alt:  #0a0a0a;
  --text-base:       #fafaf9;  /* stone-50  */
  --text-muted:      #d6d3d1;  /* stone-300 */
}

Toggle mechanism

The header includes a JavaScript toggle that adds or removes the dark class from document.documentElement and persists the preference to localStorage. The initial state is read on DOMContentLoaded to avoid a flash of unstyled content.

Tailwind integration

Tailwind's darkMode: 'class' is configured in tailwind.config.js. All color utilities like dark:text-stone-300 are available in addition to the CSS variables.
