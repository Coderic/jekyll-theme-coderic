Features Responsive design
Feature

Responsive design

Mobile-first. Every layout works from 375 px upward. The standard content container is max-w-7xl mx-auto px-6 (1280 px max).

Container rule

Header, subnav, and footer all use max-w-7xl mx-auto px-6. Every page section must use the same container to avoid misaligned content. Do not use max-w-6xl or narrower in a top-level section wrapper — that will make the content appear narrower than the chrome. 

<!-- correct -->
<section class="py-24">
  <div class="max-w-7xl mx-auto px-6">...</div>
</section>

<!-- also correct for prose -->
<article class="py-24">
  <div class="max-w-3xl mx-auto px-6">...</div>
</article>

Fixed header offset

The <main> element uses pt-40 (160 px) to clear the fixed header + subnav. Sticky sidebar elements should use top-48 (192 px) to include extra breathing room.
