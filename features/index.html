Out of the box

Features

Everything included when you set remote_theme: Coderic/jekyll-theme-coderic.

Dark mode

CSS custom properties with class-based toggle. Works without JavaScript at render time.

Responsive design

Tailwind CSS breakpoints. Mobile-first with consistent max-w-7xl container across all viewports.

Internationalization

jekyll-polyglot mirrors every page under /es/. UI strings in _data/en/ui.yml and _data/es/ui.yml.

OAuth2 / OIDC

Auth0-compatible SPA SDK. Config injected via JSON script block. Callback and profile pages included.

Typography

Display font for headings, system sans-serif for body. Fluid scale from text-sm to text-8xl.

More coming

Subnav multi-level dropdowns, Alpine.js components, and Petstore API demo are also included.
