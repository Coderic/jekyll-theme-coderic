Internationalization

The theme uses jekyll-polyglot to generate a parallel /es/ copy of every page automatically.

How it works

polyglot reads languages: ["en", "es"] from _config.yml and builds each page once per language. Pages with lang: en in front matter are the canonical English source; the Spanish build outputs under /es/. 

# _config.yml
plugins:
  - jekyll-polyglot

languages: ["en", "es"]
default_lang: "en"
exclude_from_localization:
  - "assets"
  - "404.html"

UI strings

All UI copy lives in _data/en/ui.yml and _data/es/ui.yml. Pages reference them with: 

{% raw %}{% assign t = site.data[site.active_lang].ui %}
{{ t.hero.title_part1 | default: 'Fallback text' }}{% endraw %}

Language switcher

The header renders a language link using the i18n_clean_path.html include to strip or add the /es/ prefix from the current URL.
